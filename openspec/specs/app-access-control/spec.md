# app-access-control Specification

## Purpose

在 Windows 与 iOS 上分别提供四位数字应用锁，并用每三天强制输入照片解密密码的规则帮助用户记忆密码，确保到期验证未完成时照片内容不可访问且同步保持暂停。

## Requirements

### Requirement: 两端均支持四位数字应用锁

应用 SHALL 在 Windows 和 iOS 客户端均提供四位数字应用锁设置及验证能力；该密码的用途是应用锁，不替代照片解密密码。

#### Scenario: 配置应用锁
- **WHEN** 用户在 Windows 或 iOS 客户端设置应用锁密码
- **THEN** 应用提供四位数字密码的设置方式
- **AND** 界面区分此密码与照片解密密码的用途

### Requirement: 上锁后仅显示密码输入界面

应用 SHALL 在普通应用锁处于上锁状态时仅显示密码输入界面，隐藏照片、相册和其他应用功能页面。

#### Scenario: 应用被锁定
- **WHEN** 客户端进入普通应用锁上锁状态
- **THEN** 用户只能看到密码输入界面
- **AND** 无法通过返回、导航或已有照片页面继续查看内容

#### Scenario: 应用锁密码错误
- **WHEN** 用户输入错误的四位数字密码
- **THEN** 应用保持上锁，照片和其他功能页面保持隐藏

### Requirement: 每三天强制验证照片解密密码

应用 SHALL 从上次成功输入照片解密密码开始计算 3 天周期；周期到期后必须再次正确输入该密码，不能跳过或仅用四位数字密码继续查看照片。

#### Scenario: 到期后四位密码正确
- **WHEN** 照片解密密码验证周期到期且用户输入正确的四位数字密码
- **THEN** 应用仍要求用户正确输入照片解密密码
- **AND** 照片访问保持阻断，同步保持暂停

#### Scenario: 到期验证失败
- **WHEN** 用户在到期验证页面输入错误照片解密密码
- **THEN** 照片访问继续阻断，同步继续暂停
- **AND** 不重置 3 天周期

### Requirement: 成功验证重置周期并解除到期阻断

应用 SHALL 在正确输入照片解密密码后开始新的 3 天周期，并解除此次到期造成的照片访问及同步阻断；普通应用锁仍遵守其自身的验证条件。

#### Scenario: 到期后验证成功
- **WHEN** 用户正确输入照片解密密码且普通应用锁条件也已满足
- **THEN** 用户重新获得照片访问，原同步任务可按 backup-management 继续
- **AND** 3 天周期从这次成功输入重新开始

#### Scenario: 仅解锁四位应用锁
- **WHEN** 用户仅成功输入四位数字应用锁密码
- **THEN** 该操作不被计作一次照片解密密码验证成功
- **AND** 不因此重置照片解密密码的 3 天周期
