# Spec Delta

## Purpose

为用户提供可直接在 Windows 上体验的照片管理演示会话，以虚构数据检查已确认的密码、访问控制、同步和删除交互，并让模拟能力与尚未实现的正式安全及存储功能保持明确区分。

## ADDED Requirements

### Requirement: 显示演示边界

原型 SHALL 明确标识演示性质，仅操作内置样片和虚构账号，不连接真实仓库或访问、删除用户原照片。

#### Scenario: 打开原型
- **WHEN** 用户启动 Windows 原型
- **THEN** 用户能够识别当前为演示会话
- **AND** 模拟上传或删除不会表述为真实照片已经备份或删除

### Requirement: 可重复的照片管理体验

原型 SHALL 提供虚构照片的浏览、详情、整理、收藏、导入和导出演示，并允许重置会话。

#### Scenario: 重置修改后的会话
- **WHEN** 用户在演示中更改照片、相册或仓库设置后确认重置
- **THEN** 原型恢复初始虚构数据和设置
- **AND** 不修改用户真实文件或平台账号

### Requirement: 可演示独立的访问阻断

原型 SHALL 演示四位应用锁、照片库解锁及三天复验规则，到期后阻止照片访问和同步，正确照片密码之外的操作不能解除到期限制。

#### Scenario: 验证到期时详情已经打开
- **WHEN** 照片密码验证到期且用户正查看照片详情
- **THEN** 照片详情被密码验证界面替换
- **AND** 返回操作、正确 PIN 或平台授权不能恢复照片访问或推进同步

### Requirement: 同步过程可观察

原型 SHALL 展示加密先于上传的阶段、暂停原因及成功验证后的接续，并提供可重复的网络、权限和容量失败演示。

#### Scenario: 密码已验证但网络仍不可用
- **WHEN** 用户正确输入照片密码而模拟网络故障仍存在
- **THEN** 原型解除密码造成的阻断但同步仍等待网络恢复
- **AND** 已完成与未完成项目保持准确

### Requirement: 删除范围可验证

原型 SHALL 用虚构本地原图和仓库副本状态展示三种删除范围，取消或失败不冒充成功。

#### Scenario: 仅删除仓库副本
- **WHEN** 用户在演示中确认删除仓库副本且操作成功
- **THEN** 虚构仓库副本变为不存在而本地原图仍保留
- **AND** 原型不会报告已清理真实仓库历史

### Requirement: Windows 桌面可运行

原型 SHALL 提供可启动的 Windows 桌面构建和准确的启动说明，窄窗口也能访问主要功能。

#### Scenario: 用户启动构建
- **WHEN** 用户按 README 启动 Windows 可执行程序
- **THEN** 可以进入中文演示界面并操作主要流程
- **AND** 文档如实记录已验证平台和未完成的 iOS 验收
