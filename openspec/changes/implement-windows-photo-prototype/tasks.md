# Tasks

本次实现 Windows 交互原型；关联归档任务的 Windows 部分，不将归档任务或 iOS 原生验收标为完成。所有数据、密码、账号和仓库操作均为演示。

## 1. 工程与体验基础

- [x] 1.1 建立 Flutter 工程、中文主题及响应式桌面布局；验收：工程依赖解析成功，宽窄窗口均能访问导航。
- [x] 1.2 提供本地样片、内存会话与重置功能；验收：不依赖远程图片，重置恢复初始数据，样片来源和演示边界有记录。

## 2. 照片与仓库

- [x] 2.1 实现照片网格、搜索筛选、详情、收藏和相册整理；验收：空状态、重复添加与相册移除正确，添加和移出不删除照片。
- [x] 2.2 实现模拟导入与导出；验收：仅内置样片参与，不访问用户原图，操作结果清楚说明模拟性质。
- [x] 2.3 实现 GitHub/Gitee 模拟授权、私有仓库选择和失败状态；验收：取消/失败不连接，切换平台不绕过照片密码限制。

## 3. 密码与访问控制

- [x] 3.1 实现照片密码设置提醒、四位应用锁设置、首次配置与已有库解锁；验收：不同凭据职责分离，错误密码不通过，重走设置可完成。
- [x] 3.2 实现三天到期和锁屏组合状态，关闭被锁定的详情或弹窗；验收：模型与界面测试覆盖到期、错误密码、正确 PIN、正确照片密码以及详情打开时到期。
- [x] 3.3 提供演示时间、普通锁屏同步策略和演示密码提示；验收：PIN 不重置周期，说明演示策略不确定正式方案，退出后重置可见。

## 4. 同步与删除

- [x] 4.1 实现自动队列、模拟加密/分块/上传、暂停和接续；验收：测试证明未加密不能上传，到期不推进，验证成功保留已完成与未完成进度。
- [x] 4.2 实现网络、权限、容量错误和恢复演示；验收：成功验证密码不越过其他失败条件，恢复不重复完成项目。
- [x] 4.3 实现三种删除确认、取消、失败及结果；验收：测试验证本地/仓库范围，失败不改变数据，同步删除包含另一模拟客户端，不声称清理 Git 历史。
