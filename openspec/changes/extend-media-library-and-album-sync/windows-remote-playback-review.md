## 候选 B 的具体约束（全部已批准）

1. 仅在用户打开已获准查看的远端视频／实况动态资源时绑定IPv4 `127.0.0.1` 的系统分配端口；不绑定局域网／任意地址，不增加Windows服务、入站防火墙规则或自启动。退出查看器、普通锁、到期、来源范围撤销均终止服务与连接。
2. 每次查看用现有安全随机源生成256位内存Bearer凭据及独立随机资源标识，凭据通过播放器请求头传递，不放URL查询串、不进数据库／日志／剪贴板。不使用GitHub令牌或照片密钥作为服务凭据。
3. 只接受精确Host、路径、GET／HEAD及单段Range；拒绝Origin、未知路径、上传、目录列举、重定向和多段Range。资源映射由当前认证清单和当前界面会话创建，不能传入任意本机路径、外部URL、仓库名或对象ID读取。
4. 资源字节数取已认证清单；正确处理HEAD、全请求、闭区间／开放尾部／后缀Range及416。序列化解密读取，单块仍约4MiB；只在整块AEAD认证成功且会话仍有效后输出该块所需区间。对本机慢读取设置有界等待、背压和取消，不一次加载整个大视频。
5. 继续使用WSR-1已批准512MiB密文下载缓存和真实GitHub权限核验。缓存只存密文，明文块仅内存，释放时清理可控缓冲。缓存淘汰不能删除活动块；没有已认证必要资源时不得播放或标记完整实况。
6. 单个活动查看会话、单个活动数据流；HTTP请求生命周期与播放器seek取消协调，旧响应不得拼入新位置。网络异常、块缺失／认证失败、账号失效、手动暂停或目标变化准确报错，不用零字节填补内容，不自动恢复已撤销会话。
7. 普通界面锁关闭解码器和本机读取服务，释放查看占用；已批准的后台同步按WBL-1继续。系统锁／睡眠／到期等全撤销仍遵守既有安全规则。已发送到原生解码器的帧不能假称可从所有系统内存中擦除。
8. 全资源摘要只有在完整读取全部内容后才可验证；随机播放不能冒充完整下载／恢复或上传读回验证，副本完成状态沿用原真实协议。
9. 不改远端格式、加密算法、密钥方案、照片密码／PIN规则、相册同步范围或iOS范围；不引入新的播放后端或强制转码。
