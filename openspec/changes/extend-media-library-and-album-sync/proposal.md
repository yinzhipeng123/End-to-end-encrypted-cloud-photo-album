## What Changes

- Windows 首次设置密码时增加“程序的数据保存目的地”：选择本机父目录，显示实际专用子目录，建立真实加密库并持久化启动定位；保留默认目录和已有库行为，取消选择不写入自定义目录，定位或目标异常不覆盖／重建旧库。
- 设置页展示当前实际使用的“程序的数据保存目的地”，允许选中完整路径，兼容默认和自定义目录；只在已解锁设置界面显示。
- 支持多选和当前相册／搜索／筛选结果全选，覆盖未滚动到的项目；批量删除、导出、收藏／取消收藏、加入／移出相册，以及批量上传。
- 相册增加“在所有照片中隐藏”；媒体只要属于任意一个开启此设置的相册，就从“所有照片”和“我的收藏”及其搜索、筛选、全选范围中排除，仍可在所属相册内查看。
- 照片全屏查看；Windows 和 iOS 均播放 Live Photos 的动态画面和声音，并将其作为一个管理项目，备份保留原始静态图、配对视频及关联信息。
- 纳入独立视频的导入、管理、加密同步和播放，覆盖 iPhone 普通录像、H.264／HEVC、iPhone 录制的 ProRes，以及从短视频平台保存到手机的常见视频。具体兼容样本和播放后端需验证，不能用静态封面代替播放验收。
- Windows 选择文件夹后递归导入照片和视频；运行期间发现新增文件，重新启动时补扫。源文件在外部删除／移走时保留已有仓库副本。
- iPhone 默认将权限允许访问的本地照片库全部照片和视频纳入 App，包括不属于任何普通相册的媒体；这是本机媒体导入要求，不据此增加远端原文件全量下载功能。
- 单项菜单在“查看详情”下方增加“上传”，选择模式提供批量上传；支持重新上传“删除仓库副本、保留本地”后的媒体，遵守现有加密与三天复验规则。
- 去除“新的回忆”等自动展示标题；卡片也不显示原始文件名，原始文件名只在“查看详情”中显示，卡片保留文件大小和原有操作入口。
- 移动端持续导入 iPhone 现有及新建的普通相册与成员变化。系统相册删除时保留 App 相册；App 删除相册后停止该次跟踪，提供“导入相册”手动恢复。
- **系统相册改名产生新 App 相册**：保留仍存在的旧 App 相册及成员，断开旧关联，按新名称导入新相册；即使旧 App 相册已删除／停止跟踪，也自动导入改名后的相册。
- App 内相册改名、成员调整不回写系统；系统成员变化只合并新差异，保留用户在 App 内的调整。这条冲突规则已在本次方案准备期间再次确认。
- 实施期间用户追加确认：本机路径、文件名、相册、整理和跟踪元数据也必须加密，拒绝普通 SQLite 明文索引；SQLCipher 先验证，后按 TD07 批准 Windows 正式接入，iOS 保留待验证。三天周期内允许系统安全存储辅助解锁，重启仍需四位应用锁；到期须正确照片密码，辅助解锁不能重置周期。具体密码派生、密钥及门禁方案已按 SFR-1 明确批准。

- **BREAKING（针对旧原型运行方式）**：正式运行不加载演示会话、默认密码或假仓库；未实现功能禁用并明示，不再以标注演示作为替代真实业务的交付方式。旧原型没有正式持久化数据格式，不能据此删除用户原文件或重置未来真实目录。
- 新增统一正式产品约束、实现状态分类和验收证据要求；用真实操作、重启恢复、错误路径与双端结果判定功能完成。
- 将密码学／密钥管理、加密持久化、GitHub/Gitee 授权及仓库服务从未落实的前置依赖补为明确实施任务，按八阶段安排，详见 tasks.md。
- 为真实导出、三种删除、下载恢复和失败恢复补齐可验证业务结果；不增加自动全量下载功能。
- technical-decisions.md 保留选项比较；TD01–TD06、TD07 Windows 数据库接入、TD08-A GitHub 授权、TD09-A GitHub 访问协议及 WIR-1 本机 TD11-W／TD13-W 已批准。Gitee、最终媒体格式、跨设备身份／版本、网络调度及删除策略等未决项继续确认。SQLCipher iOS 接入尚待验证，media_kit 保持已获准接入验证；历史结果不等于正式双端验收。

## Capabilities

### New Capabilities

- `production-readiness`：正式运行数据真实性、未实现状态、真实操作结果及可追溯验收的统一交付约束。

- `album-visibility`：按相册设置控制聚合视图的媒体可见性及相关计数、搜索和批量范围。
- `media-viewing`：照片全屏查看、Live Photos 与独立视频双端播放，以及锁定时的媒体访问阻断。
- `windows-media-import`：Windows 文件夹递归发现、运行期监测与启动补扫，覆盖照片和视频。
- `ios-media-import`：默认纳入 iPhone 本地照片库全部可访问媒体，独立于普通相册的成员分类。
- `ios-album-import`：系统相册单向导入、成员差异合并、改名产生新相册、删除后的停止跟踪和手动重导入。

### Modified Capabilities

- `vault-onboarding`：真实照片库初始化、凭据建立、敏感材料处理和失败保留。
- `app-access-control`：跨启动锁定、可信复验状态、真实验证和旧访问会话失效。
- `repository-connection`：真实授权、私有仓库查询／权限校验和令牌生命周期。
- `device-recovery`：无原文件／旧缓存的独立客户端解密恢复及错误结果。

- `photo-library`：明确媒体范围、多选／全选和批量管理，取消展示名称，保留原删除语义。
- `backup-management`：将自动同步扩展到媒体项目，增加单项／批量手动上传及删除仓库副本后的显式重传。
- `encrypted-storage`：将上传前加密与客户端解密边界扩展到视频和 Live Photos，保留完整原始资源，并要求本机元数据落盘加密。
