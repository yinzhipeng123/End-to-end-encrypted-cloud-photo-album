## 资源与失败边界

- 远端单次封面处理从开始执行起限45秒，累计认证块读取最多64 MiB；首帧等待最多20秒。排队不启动解码或读取。超时／预算不足显示封面不可用，可手动重新读取，不提供假封面。
- 原生缩放目标256像素，持久化PNG最多256 KiB；串行解码。封面失败不等于原媒体不可播放，封面成功不等于完整副本校验通过。
- 无法确认的实况时长保持未知，不使用静态图片播放器的默认时长。
- 版本、目标仓库、查看权限和取消令牌持续核验。关闭查看器、换库或锁定撤销请求；缓冲清理范围与既有WRP-1相同，不声称原生解码器或操作系统内存完全可擦除。
- 队列“此版本上传任务已完成”为历史任务状态，当前副本须另查当前receipt并校验；文件名仍只在查看详情展示。
