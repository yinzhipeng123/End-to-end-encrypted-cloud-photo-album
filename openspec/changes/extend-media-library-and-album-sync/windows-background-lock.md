# WBL-1 — Windows 界面锁与后台同步

## Approval

## Behavior

- 必须在本次进程已通过真实 PIN 和照片密码期限检查后建立后台会话。启动 PIN 页不自动读取辅助材料来启动同步。
- 最小化／手动锁：立即撤销界面代次、关闭界面 SQLCipher 连接、销毁整理与选择、取消查看读取并清理可控明文缓冲。后台 SQLCipher 连接、随机密钥会话、来源监听与既有仓库授权保留；继续完整导入、加密、上传、认证清单和读回校验。
- 界面锁不是进程密钥清除。获准后台会话在进程内仍具有完成同步所需的加解密能力；不声称抵御进程内存读取。照片密码原文不新增保存，落盘元数据与内部暂存仍保持加密。
- 系统会话锁定／断开、睡眠／恢复、退出／重启、72 小时到期、时间异常、远端密码变更及必要安全材料异常仍全撤销。原 PIN 重试限速不变，第十次错误要求照片密码并撤销后台。
- 普通 PIN 错误和重试等待不停止原有有效后台任务；正确 PIN 只新开界面会话，不重建后台、不延长期限。手动同步暂停始终独立。
- 授权登录、仓库选择等交互请求在界面锁时取消，后台同步的令牌刷新和仓库请求继续。已明确启动的初始化／完整性校验可随有效后台任务完成，不以界面锁伪造回滚。所有查看请求单独撤销，不能迟到显示明文。
- 后台每次访问检查门禁，并保留每秒持久期限检查；没有后台服务、开机自启或退出后同步。

## Implementation

1. ReverificationGate 增加仅撤销 PIN 验证操作和重新验证界面 PIN 的接口；完整 lock 保持全撤销语义。
2. VaultController 使用独立界面／后台 SQLCipher 连接；界面连接绑定访问代次，旧连接关闭不可复活。普通 lock 仅撤销界面，系统与失败路径使用 suspend。共享同一已经批准的随机目录密钥，不改变磁盘格式。
3. 本机预览与远端查看具有独立取消令牌／代次和缓冲清理，不与上传读取混用。整理服务只使用界面连接。GitHub 交互请求与后台访问区分取消范围。
4. Windows 原生通道为最小化与系统安全事件发送不同消息，Flutter detached 和不可验证的平台状态执行全撤销；不因 hidden 的重复事件重新开放后台。
5. 设置及同步文案准确说明当前行为。UI、协议测试、真实本机和真实 GitHub 证据分别记录。
6. 原生 runner 在最小化前覆盖上一帧；恢复后等待密码页渲染完成才移除遮挡，避免显示旧照片画面。每次安全事件递增遮挡代次，旧帧回调不能移除新遮挡；遮挡只保护显示，不改变后台工作权限。
