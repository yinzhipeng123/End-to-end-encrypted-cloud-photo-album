# Spec Delta

## ADDED Requirements

### Requirement: 仓库恢复不携带本机目录密钥
Windows GitHub恢复 SHALL 使用WSR-1的188字节主密钥包装投影和加密清单；正确照片密码通过固定KDF和AEAD取得原主密钥，新设备建立独立随机目录密钥、PIN及平台材料，不上传或复制源设备目录密钥和本机访问状态。

#### Scenario: 全新目录恢复
- **WHEN** 独立客户端没有发送端原图、数据库、DPAPI材料和缓存
- **THEN** 仅从实际仓库及正确照片密码恢复认证原始资源，并建立独立本机保护
- **AND** 错误密码、未知版本或不同库身份不得覆盖当前照片库

### Requirement: 独立客户端从仓库真实恢复
应用 SHALL 在没有原文件和既有媒体缓存的客户端，使用真实仓库内容及获准凭据恢复照片、视频和 Live Photo 原始资源，验证完整性及关联后提供查看或导出；平台授权或本机旧路径不能替代恢复。

#### Scenario: 在另一端恢复原始媒体
- **WHEN** 已获仓库访问权的独立 Windows 或 iOS 客户端通过照片库解锁并请求恢复已完整备份媒体
- **THEN** 客户端实际下载、验证并解密仓库资源，恢复原始字节及必要关联
- **AND** 不读取原客户端路径或使用内置样片冒充恢复结果

### Requirement: 不完整或损坏恢复不得报告成功
应用 SHALL 在错误密码、缺块、缺失配对资源、损坏、未知格式或读取失败时保留准确失败状态及已有数据，不生成假的完整媒体记录。

#### Scenario: Live Photo 缺少必要资源
- **WHEN** 仓库恢复过程中发现静态图、配对视频或必要关联不完整
- **THEN** 应用报告该项目尚未完整恢复
- **AND** 不把静态图展示当作完整实况恢复成功

### Requirement: 恢复范围遵守用户操作和访问条件
应用 SHALL 按获准查看、导出或恢复请求获取所需资源，持续遵守应用锁和三天复验；iPhone 默认纳入全部本机媒体的要求不自动触发仓库原文件全量下载。

#### Scenario: 恢复期间验证到期
- **WHEN** 用户请求的恢复尚未完成而照片密码复验到期
- **THEN** 访问和同步按现有规则阻断，实际未完成状态保留
- **AND** 不绕过验证展示解密内容，也不扩大到未请求的全库下载
