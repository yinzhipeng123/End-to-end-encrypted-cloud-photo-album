# Spec Delta

## ADDED Requirements

### Requirement: Windows 界面锁与后台工作分别授权
Windows 应用 SHALL 在最小化或手动锁定时仅保留密码界面，撤销旧界面目录连接、整理服务、预览／播放读取及回调；已实际解锁且未到期的后台会话保留必要密钥、加密目录及仓库访问，继续发现新增、导入、加密、上传和读回校验。普通窗口失焦不锁定；后台能力不能用作界面或重启 PIN 的绕过。

#### Scenario: 最小化或手动锁后新增文件
- **WHEN** 已解锁进程最小化或手动锁定，已选来源中有新增媒体且其他同步条件满足
- **THEN** 界面只显示密码页，旧查看句柄与回调失效，后台继续真实导入和同步
- **AND** 正确 PIN 重新开放界面而不重建后台服务、不延期、不产生第二条同步任务

#### Scenario: 系统锁屏睡眠或强制安全撤销
- **WHEN** Windows 会话锁定／断开、睡眠、程序退出，或 72 小时到期、时间异常、远端改密要求重新验证
- **THEN** 撤销前后台会话、关闭加密目录并取消在途读取和请求，保留真实已提交进度
- **AND** 重启或系统恢复不会自动恢复后台；需要满足原 PIN 或照片密码条件

#### Scenario: 普通锁下错误 PIN 与十次错误
- **WHEN** 后台仍运行时输入错误 PIN
- **THEN** 前九次按原规则限制重试且界面保持锁定，不因普通输入错误中断后台
- **AND** 第十次或重试材料异常要求照片密码并撤销后台；正确 PIN 不延长 72 小时

#### Scenario: 原手动暂停保持
- **WHEN** 用户已暂停同步，随后最小化、锁定或重新解锁
- **THEN** 手动暂停保持，不能由锁定状态转换解除

### Requirement: iOS 锁定边界保留
 iOS 应用 SHALL 保留 SFR-1 的后台锁定和会话撤销规则；本次 Windows 调整不授予 iOS 持续后台运行能力，iOS 实施和验证仍延后。

#### Scenario: iOS 进入后台
- **WHEN** iOS 客户端进入 inactive 或 background
- **THEN** 分别按原约定遮挡／停止播放和执行 PIN 锁及同步撤销

### Requirement: PIN 与照片密码重试状态受保护保存
应用 SHALL 按 SFR-1 保存独立凭据校验及重试状态：PIN 错误第 5 次起分别等待 30／60／120／240／480 秒，第 10 次要求正确照片密码；照片密码第 5 次失败起等待 30 秒，随后翻倍且上限 900 秒；重启不得清零，状态写失败不能放行。

#### Scenario: PIN 连续错误后重启
- **WHEN** 用户在等待或要求照片密码状态下重启
- **THEN** 继续执行已保存限制，不新增免费尝试或延长照片密码期限
- **AND** 不因失败次数删除任何原图、目录或仓库

#### Scenario: 用正确照片密码重设 PIN
- **WHEN** 用户通过真实照片密码验证并设置新的四位 ASCII 数字 PIN
- **THEN** 按新 PIN 验证普通锁，已成功的照片密码验证可以启动新周期
- **AND** 不通过清空真实数据重设凭据

#### Scenario: 初始化中断或 PIN 材料缺失
- **WHEN** 用户正确输入照片密码，但本机 PIN 校验材料缺失、损坏或格式无效，且没有显式提交新 PIN
- **THEN** 应用保持照片密码页面并提示使用已有的“同时重新设置本机四位应用锁”流程
- **AND** 不发布新的辅助解锁期限、不提示输入尚不存在的 PIN；显式新 PIN 仍须正确照片密码及两次一致输入

### Requirement: 复验使用独立七十二小时和时间异常边界
应用 SHALL 对每台设备从本端正确照片密码验证起计算 259200 秒，按 SFR-1 用受保护 UTC 截止／最大已观察时间及含挂起时间的单调计时核对。超过 60 秒的规定时间异常或状态不可确认时要求照片密码，小幅回拨不得延后期限。

#### Scenario: 另一设备验证或本机时间异常
- **WHEN** 另一设备成功验证，或本端发生超过容差的时间异常
- **THEN** 前者不延长本端周期，后者阻断辅助解锁并要求本端正确照片密码
- **AND** 不引入联网时间服务，不声称能检测任意完整系统快照回退

### Requirement: 辅助材料按批准平台属性保护
应用 SHALL 使用 Windows 用户范围 DPAPI 及 iOS 本设备、设备解锁时可访问且不参与同步的 Keychain 保存批准辅助材料。材料绑定安装、库、包装代次和期限；PIN 校验材料及重试状态受保护，不保存 PIN 原文。

#### Scenario: 到期或系统材料不可用
- **WHEN** 辅助材料到期、身份不符、损坏或平台拒绝读取
- **THEN** 不生成可访问会话，要求真实照片密码流程
- **AND** 不回退明文文件、默认凭据或重新计算三天期限

### Requirement: 重启保持独立应用锁及复验期限
应用 SHALL 在已配置客户端每次重启后要求本端四位 PIN，并保存照片密码最后成功验证所需的受保护状态；三天内可以使用系统安全存储辅助解锁，但辅助解锁、PIN、重启及平台授权均不延长三天周期。

#### Scenario: 三天内重新打开已配置客户端
- **WHEN** 用户重启客户端且未到照片密码复验期限
- **THEN** 先显示应用锁，只有本端正确 PIN 及必要访问条件满足后才能查看内容
- **AND** 不重置照片密码最后成功验证时间

#### Scenario: 到期后重启
- **WHEN** 照片密码复验已到期且客户端重新打开
- **THEN** 正确 PIN 或系统辅助材料均不能替代正确照片密码验证
- **AND** 访问及同步继续阻断

### Requirement: 解锁依赖真实安全验证
应用 SHALL 使用批准的真实凭据校验及解密访问机制，不通过演示字符串、初始默认密码、空库回退或失效辅助材料取得正式访问。

#### Scenario: 验证错误或辅助材料不可用
- **WHEN** 密码验证失败或系统辅助材料无法按批准方案使用
- **THEN** 应用保持相应阻断并提供真实验证或恢复提示
- **AND** 不自动解锁、延期或伪造解密结果

### Requirement: 时间与访问变化不产生隐式放行
应用 SHALL 按批准的时钟异常及在途工作策略处理期限，确保到期后不继续发起被阻断工作，旧页面、媒体会话及异步结果不能恢复内容访问。

#### Scenario: 到期时存在工作和旧回调
- **WHEN** 期限到达而媒体正在播放或同步尚未完成
- **THEN** 应用停止观看并按批准边界暂停同步，保存实际结果
- **AND** 旧回调或重启不能解除到期阻断，不能以重置计时处理异常
