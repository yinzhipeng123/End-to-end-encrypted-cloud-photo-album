# Spec Delta

## Purpose

定义正式应用在真实业务数据、操作结果、功能可用性和验收证据方面的统一交付契约，使用户能够分辨已完成操作与未实现能力，并确保界面、模拟测试或编译结果不能替代真实文件、密码学、持久化及平台服务的业务结果。

## ADDED Requirements

### Requirement: 功能状态准确对应当前构建
应用 MUST 显示实际构建版本并提供具体能力说明；不能用固定笼统开发标签代替功能状态，也不能通过移除标签将未实现或未验收能力宣称完成。

#### Scenario: 用户查询当前版本和未开放能力
- **WHEN** 用户打开关于窗口或未开放平台入口
- **THEN** 显示实际版本及具体未开放能力；Gitee未实现时禁用其入口
- **AND** 区分Windows已接入代码、待业务验收与暂缓的iOS，不显示假成功

### Requirement: 分平台实施保留完整产品需求
产品 MUST 按用户最新授权先实现、验收并运行 Windows 客户端，保留全部 iOS 需求和未完成记录；iOS 缺少构建或真机条件不阻断满足 Windows 前置条件的工作。Windows 完成不代表 iOS 或双端整体完成。

#### Scenario: Windows 任务通过而 iOS 尚未执行
- **WHEN** Windows 部分具有真实实现及所需验收证据，而 iOS 部分尚未实施或验证
- **THEN** 单独记录 Windows 完成和 iOS 暂缓，允许继续后续 Windows 任务
- **AND** 不删除 iOS 需求、不勾选其验收、不将部分可用包称为完整产品

### Requirement: 正式运行使用真实业务来源
应用 MUST 使用真实媒体、实际配置和真实业务服务；首次未配置或没有媒体时显示准确的初始化或空状态，不自动建立虚构账号、仓库、照片、密码或副本记录。

#### Scenario: 全新客户端首次打开
- **WHEN** 用户首次启动尚未建立真实照片库的正式客户端
- **THEN** 应用提供真实初始化流程或空状态
- **AND** 不展示自动样片、假仓库或虚构已备份结果

### Requirement: 不以模拟数据代替业务数据
应用 MUST 从真实来源及已确认结果建立业务记录，不能通过内置样片、虚构大小或预置远端存在标志替代用户媒体；未知属性须准确表示未知。

#### Scenario: 媒体属性尚未读取
- **WHEN** 应用未能取得媒体时长、封面或副本结果
- **THEN** 显示相应未知、不可用或待核对状态
- **AND** 不填入构造数据冒充真实属性或备份

### Requirement: 成功提示来源于真实执行结果
应用 MUST 仅在对应业务真实完成并核对结果后显示成功；按钮点击、排队、计时结束、内存状态变化或模拟返回值均不能作为操作成功依据。

#### Scenario: 上传请求仅已排队
- **WHEN** 用户提交媒体上传但远端完整结果尚未确认
- **THEN** 应用显示实际待处理或进行状态
- **AND** 不显示备份完成或仓库副本已存在

### Requirement: 文件操作真实作用于指定资源
应用 MUST 对用户确认范围中的真实文件或系统媒体执行读取、导出、恢复和删除，并核对实际结果；缓存操作或内存记录变化不能冒充原资源操作。

#### Scenario: 文件写出失败
- **WHEN** 导出目标因权限或空间问题未完成实际写入
- **THEN** 应用报告真实失败或部分结果
- **AND** 不显示该资源已成功导出

### Requirement: 安全能力使用真实密码学实现
应用 MUST 使用经确认方案的真实加密和解密实现并检查完整性；字符串比较、状态标志、编码转换或扩展名变化不能满足照片库安全要求。

#### Scenario: 密文无法验证或解密
- **WHEN** 输入错误凭据或待恢复密文损坏
- **THEN** 应用拒绝报告成功解密并保留可诊断错误
- **AND** 不回退到样片、原图缓存或演示成功流程

### Requirement: 业务数据按设计持久化
应用 MUST 按设计保存来源、媒体索引、整理、跟踪、任务、副本及访问期限等业务状态，并保护要求加密的数据；运行时选择、弹窗等临时界面状态不因此强制持久化。

#### Scenario: 保存整理后退出重启
- **WHEN** 应用报告整理保存成功且随后退出并重新打开
- **THEN** 在满足访问条件后恢复已提交业务记录
- **AND** 不能用初始样片或重新创建空库替代记录恢复

### Requirement: 未实现能力明确禁用
应用 MUST 将尚未实现的功能标记未实现并禁用执行入口，不用假按钮、模拟成功或降级演示代替；开发阶段的部分能力不构成完整正式交付。

#### Scenario: 缺少真实执行服务
- **WHEN** 用户进入尚未接入真实执行服务的功能区域
- **THEN** 应用准确展示未实现状态并禁止发起假操作
- **AND** 不因标注演示而允许模拟业务结果进入用户记录

### Requirement: 功能完成有可追溯验收证据
产品 MUST 为每项必需功能保留与规格、实现版本、平台及实际结果对应的验收证据，区分界面／规则、模拟、局部真实实现与正式验收；测试替身只在隔离测试使用。

#### Scenario: 只有界面或模拟测试通过
- **WHEN** 某项能力尚无规定平台的真实业务验证，尽管界面测试或编译已经通过
- **THEN** 该能力仍记录为未完成或未验证
- **AND** 不据此宣布正式交付完成或用文档校验代替业务验收
