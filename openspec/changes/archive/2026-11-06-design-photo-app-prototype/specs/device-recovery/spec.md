# Spec Delta

## Purpose

定义用户在另一台 Windows 或 iOS 设备连接已有加密照片库时的基本解锁边界，使仓库账号授权与照片解密凭据保持分离，并使用用户记忆的照片解密密码而非未确认的恢复码流程。

## ADDED Requirements

### Requirement: 平台授权与照片解密分离

应用 SHALL 区分仓库访问授权和照片解密权限，不能仅因 GitHub 或 Gitee 授权成功就把已有加密照片库视为已解锁。

#### Scenario: 新设备刚完成平台授权
- **WHEN** 新设备已获仓库访问授权，但尚未通过该照片库的密码解锁流程
- **THEN** 应用保留照片解密密码输入步骤
- **AND** 不将平台登录成功直接显示为照片解密成功

### Requirement: 使用照片解密密码解锁已有照片库

应用 SHALL 使用照片解密密码验证已有照片库的解锁；错误密码不能被当成成功解锁，四位数字应用锁密码不能替代照片解密密码。

#### Scenario: 正确密码解锁
- **WHEN** 用户在已有照片库的解锁流程中输入正确照片解密密码
- **THEN** 应用可以恢复对该照片库的解密访问，且仍遵守 app-access-control 的应用锁条件

#### Scenario: 错误密码解锁
- **WHEN** 用户输入错误照片解密密码
- **THEN** 照片库保持未解锁状态
- **AND** 应用不展示已成功解密的照片内容
