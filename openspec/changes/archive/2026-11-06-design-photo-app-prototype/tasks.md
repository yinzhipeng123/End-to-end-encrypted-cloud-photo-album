# Tasks

以下任务供后续实施 Flutter 交互原型使用，当前均未实施；本次只更新文档。需求见七份 `specs/*/spec.md`，已确认决定与未决事项见 [design.md](design.md)。

原型仅使用虚构账号、仓库、照片和演示密码，明确标识模拟性质。它不连接真实账号或仓库，不实现真实密码学，不读取或删除用户原照片。不得把模拟加密、上传、解锁或删除的成功视为正式能力已通过验证。

设计中的 Q01–Q09 仍是相关正式功能的前置决策；若某个问题影响原型要表达的行为，应先澄清该问题，再推进对应任务。可控演示时间、虚构任务和示例媒体只是原型验证手段，不确定正式计时、同步协议或媒体范围。

## 1. 原型范围与基础

- [ ] 1.1 按七份规格整理 Windows 和 iPhone 的页面流程及状态草图，将导航和布局标为原型建议；验收：草图覆盖仓库选择、两种密码、三天验证、照片管理及三种删除方式，并列明受未决事项影响的流程。
- [ ] 1.2 在本项目建立 Flutter + Dart 原型工程，记录实际工具版本、依赖选择及可用的构建验证环境；验收：Windows 原型能够启动，README 提供可重复的启动步骤，iOS 尚不可验证的部分如实标注。
- [ ] 1.3 建立虚构演示数据、演示状态和重置入口；验收：演示说明可见，重置可恢复初始场景，README 明确演示凭据不能使用真实密码，运行不依赖真实照片或账号。

## 2. 仓库连接与照片密码

- [ ] 2.1 实现 GitHub、Gitee 模拟授权及私有仓库选择；验收：两种平台均能完成选择，模拟取消或失败时不显示已连接，不把支持两种平台自动表现为双端镜像。
- [ ] 2.2 实现照片解密密码的演示设置流程和记忆提示；验收：明确提示每 3 天必须正确输入，流程不要求密钥文件或恢复码，界面能区分照片密码与平台授权。
- [ ] 2.3 实现另一台设备连接已有照片库的模拟解锁；验收：平台授权成功后仍须正确照片密码，错误密码和四位应用锁密码不能解锁；在原型说明中记录成功和失败的演示方式。

## 3. 应用锁与三天强制验证

- [ ] 3.1 实现两端四位数字应用锁的演示设置、上锁和验证；验收：上锁后只显示密码输入界面，错误密码、返回操作及已有页面入口不能展示照片；演示上锁入口不代替正式触发策略。
- [ ] 3.2 使用可控演示时间实现三天到期验证；验收：针对未到期、到期、错误照片密码、正确 PIN、重新平台授权和正确照片密码编写状态转换测试，验证只有正确照片密码才能解除到期阻断并重置周期。
- [ ] 3.3 连接应用锁和到期验证的组合状态，记录演示操作；验收：两种限制同时存在时，照片访问满足各自条件才能恢复，普通 PIN 解锁不重置三天周期，文档不将普通上锁的同步行为写成已确认规则。

## 4. 照片管理与删除选择

- [ ] 4.1 实现双端虚构照片的浏览、整理、导入和导出演示；验收：桌面与手机布局均可完成这些操作，并能区分本地原照片与仓库副本，Windows 模拟同步后仍保留普通原照片状态。
- [ ] 4.2 实现三种删除范围的选择和结果演示；验收：逐项检查“删除本地保留仓库”“同步删除”“删除仓库保留本地”的结果，取消不改变数据，不能把清理 App 缓存演示成原照片已删除。
- [ ] 4.3 展示模拟删除未完成或失败时的状态，并记录各平台演示方法；验收：未成功的 Windows 原文件或 iPhone 系统相册原照片删除不会显示为完成，不暗示已永久清理仓库历史；删除前校验和防止重新同步的待决规则继续保留在设计中。

## 5. 加密存储与自动同步演示

- [ ] 5.1 实现模拟加密、密文分块和上传的顺序；验收：演示状态不能从未加密直接进入上传，示例说明每块尽量在 50 MB 以内的目标，不固定正式格式、算法或块大小参数。
- [ ] 5.2 实现模拟新增照片后的自动排队和同步进度；验收：已完成和未完成项目可辨识，重复刷新不重复统计完成项，演示不添加产品自定的照片库总容量上限。
- [ ] 5.3 将到期验证与同步暂停、恢复连接；验收：状态测试覆盖到期后新任务等待、错误密码保持暂停、正确密码接续任务和保留已完成进度，模拟队列暂停不被描述为正式在途请求处理方案。
- [ ] 5.4 提供模拟网络、仓库权限或容量限制导致的失败场景，并更新演示说明；验收：失败可见且不误报成功，解除照片密码到期阻断不会绕过其他失败条件，不引入未经确认的网络默认策略。

## 6. 双端整体验证

- [ ] 6.1 运行 Flutter 静态分析、已有行为测试和 Windows 构建，走查首次设置至同步、到期、恢复及三种删除的完整流程；验收：记录实际结果和未解决问题，流程同时符合七份规格，原型模拟边界清楚。
- [ ] 6.2 在具备 iOS 构建及设备条件后验证同一流程，检查手机输入、布局和锁定状态；验收：记录实际构建环境与测试设备，若条件不具备则保留未完成状态，不以 Windows 或网页验证替代 iOS 验收。
